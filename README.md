# Лабораторная работа №2: Защита ПО и триальный период (Trial Protection)

Приложение на C++ (WinAPI) с демонстрацией механизма ограничения использования (Start-limited), интеграцией с системным реестром Windows, инсталлятором и деинсталлятором.

---

## 📌 Функционал

1. **Основная программа (`app.exe`):**
   * Графический интерфейс на чистом WinAPI.
   * Запрос ФИО пользователя и сохранение в файл `users.txt`.
   * Проверка на дубликаты: если такое ФИО уже есть в файле, выводится предупреждение.
   * Триальный механизм: лимит на **5 запусков**.
   * После добавления записи программа сообщает об оставшемся количестве запусков и завершает работу.
   * При исчерпании лимита доступ блокируется до запуска окна.

2. **Инсталлятор (`installer.exe`):**
   * Self-contained (единый исполняемый файл с зашитыми бинарными ресурсами `app.exe` и `uninstaller.exe`).
   * Проверяет реестр на предмет предыдущих установок:
     * При повторной установке сообщает о старых лимитах и не позволяет их сбросить.
     * При первичной установке информирует о доступных 5 запусках.
   * Разворачивает файлы приложения в директорию `C:\Lab2App`.

3. **Деинсталлятор (`uninstaller.exe`):**
   * Удаляет исполняемые файлы программы и базу данных `users.txt`.
   * **Сохраняет записи в системном реестре** для предотвращения сброса триала переустановкой.
   * Использует отложенное фоновое удаление через `cmd.exe` для корректного самоуничтожения занятого процесса.

---

## 🛠 Технологический стек

* **Язык:** C++ (стандарт C++11 и выше)
* **API:** Windows API (WinAPI) в режиме Unicode (`UTF-16`)
* **Компилятор:** MinGW GCC (`g++`, `windres`)
* **Хранилище состояния:** Системный реестр Windows (`Windows Registry`)

---

## 🚀 Инструкция по сборке

Для сборки всех компонентов потребуется компилятор MinGW с поддержкой утилиты `windres`.

Сборка выполняется последовательно следующими командами:

```bash
# 1. Сборка основной программы
g++ main.cpp -o app.exe -mwindows

# 2. Сборка деинсталлятора
g++ uninstaller.cpp -o uninstaller.exe -mwindows

# 3. Компиляция ресурсов (вшиваем app.exe и uninstaller.exe)
windres resources.rc -O coff -o resources.res

# 4. Сборка единого инсталлятора
g++ installer.cpp resources.res -o installer.exe -mwindows
```

После этого будет получен файл `installer.exe`, готовый к распространению.

## 💻 Инструкция по использованию

1. Запустите `installer.exe` для установки программы в систему.
2. Перейдите в папку `C:\Lab2App` и запустите `app.exe`.
3. Введите ФИО и нажмите **«Сохранить»**:
   * При первичном вводе данные сохранятся в `users.txt`, программа покажет остаток запусков и закроется.
   * При повторном вводе того же ФИО программа сообщит, что пользователь уже существует.
4. После 5-го запуска программа уведомит об исчерпании лимита и откажет в доступе.
5. Для удаления запустите `C:\Lab2App\uninstaller.exe`.
6. При попытке повторно запустить `installer.exe` программа уведомит, что лимит уже был исчерпан ранее.

## 🔓 Механизм регистрации в системе и «взлом» защиты

Программа регистрирует состояние триального периода в системном реестре Windows:

* **Ветка:** `HKEY_CURRENT_USER`
* **Путь:** `Software\Lab2App`
* **Параметр:** `LaunchCount` (тип `REG_DWORD`)

### Как «взломать» программу (сбросить лимиты):

**Способ 1. Через графический редактор реестра:**
1. Нажмите `Win + R`, введите `regedit` и нажмите `Enter`.
2. Перейдите по пути: `HKEY_CURRENT_USER\Software\Lab2App`.
3. Дважды щелкните по параметру `LaunchCount` и установите значение `0` (или удалите раздел `Lab2App`).

**Способ 2. Через командную строку (CMD):**
Выполните команду для мгновенного удаления ключа:
```cmd
reg delete HKCU\Software\Lab2App /f
```

После сброса программа снова посчитает установку первичной и предоставит 5 пробных запусков.
